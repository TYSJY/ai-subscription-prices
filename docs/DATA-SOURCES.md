# 数据来源与比较口径

## 1. App Store 地区标价

价格来自 `lib/catalog.ts` 指定的四款产品在 Apple App Store 的地区页面。页面公开的内购项可能包括不同周期、同名多价或不完整套餐资料。工具保留同名多价提示；周期不明确时显示“周期未标注”，不会把年价按月价显示。

目录中的地区不等于都能取得价格。未上架、页面缺少内购价格、来源错误或限流都会保留对应状态。若地区页面跳转到其他地区，不混用跳转后的价格。

## 2. 参考汇率

来源为 ExchangeRate-API 的 USD 基准公开接口。当地币转美元后，再按同一组汇率换算人民币。缺少汇率时保留空值。参考汇率超过 48 小时会暂停最低价排名。

实际银行卡扣款还可能包含发卡行汇差、手续费或其他结算差异。

## 3. 税前估算

计算式：

```text
税前估算 = 原标价 / (1 + 参考税率 / 100)
```

该计算假设原标价包含相应税率。来源不提供逐条税费明细，因此结果只是统一假设下的比较值，不能证明该价格确实含税，也不代表购买者具备免税资格。税率来源、核查日期、地方差异或复合税处理记录在 `lib/tax-rates.mjs`。

缺少可计算税率时，原价继续展示，该地区不进入税前估算排名。税率核查日期不会随着价格或汇率刷新而自动更新。

## 4. 最低价范围与时效

只在同套餐可比较记录中排序，使用成功查询、6 小时内的价格及可用参考汇率。不能把结果理解成覆盖所有国家、所有支付渠道的最终最低扣款金额。

## 5. 网页结算示例

`lib/checkout-observations.ts` 保留一条此前已在公开查价站展示的匿名智利结算金额转录，未包含截图、账号或付款个人信息。该记录由用户于 2026-09-20 提供，截图拍摄时间不明，未独立实时核价。

刷新汇率只改变金额换算，不更新原报价日期，也不会让该记录进入实时最低价排名。

## 6. 更新机制

- 自动更新仅在页面打开时运行，间隔 30 分钟。
- 服务器使用 D1 缓存、刷新租约和冷却时间。
- 来源出现限流时暂停后续查询，保留已缓存结果。
- 本版本没有持久化价格时间序列，也没有服务端定时全量采集任务。
