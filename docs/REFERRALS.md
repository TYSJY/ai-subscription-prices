# 来源标记与引流入口

## 已配置

| 入口 | 目标 | UTM 来源 |
| --- | --- | --- |
| 中文 README 在线查价 | 查价站 | github / readme |
| 英文 README 在线查价 | 查价站 | github / readme_en |
| README 订阅服务 | gptpro20.com | github / readme 或 readme_en |
| 查价站服务按钮 | gptpro20.com | ai-pricing-live / referral |
| Issue 模板服务入口 | gptpro20.com | github / issue_template |

当前链接可区分直接来自 GitHub 的访问，以及来自查价站服务按钮的访问。查价站按钮不会自动保留访问查价站之前的所有来源，不能据此声称已识别完整的多次访问路径。

## 还需要服务网站配合的统计

UTM 是链接参数，本项目未部署订单分析系统，也没有访问 gptpro20.com 的订单后台。要衡量转化，需要在接收网站记录 UTM，并根据实际使用的咨询或订单系统建立关联。

建议统计：带来源标记的访问、咨询数、支付成功订单数，以及退款后有效订单数。不要把按钮点击直接当作成交。

## 日常维护

- 发布可以复核的价格解析、数据来源或税率修正。
- 使用 Issues 收集产品与地区的查询异常。
- 在允许项目分享的社区发布真实使用说明和工具链接，明确维护者的商业关联。
- 仓库的主要内容保持为工具代码、数据说明和使用文档。
